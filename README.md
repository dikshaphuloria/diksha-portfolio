# Diksha Phuloria — Personal Portfolio

A personal portfolio website built with Next.js, showcasing my academic background, 
projects, and a little bit about who I am beyond the resume.

🌐 **Live Site:** [your-vercel-url.vercel.app](https://your-vercel-url.vercel.app)

## Pages
- **Home** — Introduction with a short summary and quick navigation
- **Academic & Experience** — Education, work experience, skills, and projects
- **About Me** — My journey, interests, fun facts, and certifications
- **Contact** — Email, GitHub, and LinkedIn

## Tech Stack
- [Next.js 15](https://nextjs.org/) — React framework with App Router
- [TypeScript](https://www.typescriptlang.org/) — Type safety
- [Framer Motion](https://www.framer.com/motion/) — Page animations
- [Lucide React](https://lucide.dev/) — Icons
- CSS Variables — Theming and consistent styling

## Running Locally
```bash
git clone https://github.com/dikshaphuloria/diksha-portfolio.git
cd diksha-portfolio
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000)
